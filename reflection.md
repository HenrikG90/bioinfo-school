# Reflection

As clinical neuroscience PhD student with a background in psychology and no prior programming 
or biology training, this course was as much about learning 
to navigate an unfamiliar environment as it was about learning 
to use agents. Git, terminals, and IDEs were a bigger initial 
barrier than the AI concepts themselves.

What I would trust an agent to do in my research: write and 
run reusable analysis scripts on structured data I already 
understand clinically — calculating metabolite ratios like 
KTR, generating summary statistics, producing plots. I trust 
this because I can validate the output myself using domain 
knowledge, the same way I learned to check that a CDS 
translation starts with M and ends in a stop codon, even 
without understanding the underlying code.

What I would not trust an agent with: anything requiring 
biological knowledge I don't have to validate — protein 
structure interpretation, genomic coordinate systems, or 
any pipeline where I can't independently sanity-check the 
result. The trap exercise made this concrete: the agent can 
produce confident, plausible-looking output that is silently 
wrong, and without domain expertise on my side, I would have 
no way to catch it. I also would not trust an agent to make 
clinical or scientific judgment calls — only to support the 
mechanical parts of analysis that I can verify.

The biggest gap by the end of four weeks is not technical 
fluency but biological fluency outside my own subfield — 
weeks 1-2 (LLMs, agents, validation) mapped directly onto 
skills I can use immediately; week 3 (protein structures, 
embeddings) was the hardest to connect to my actual research.
